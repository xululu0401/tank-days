# 这缸水还能撑几天（tank-days）

按你鱼缸的真实尺寸、鱼重与投喂量，算出硝酸盐**每天涨多少 mg/L**、**不换水还能撑几天**、
以及**你现在的换水节奏最后会稳在多少**；再给出「多换水 / 少喂 / 加水草 / 换大缸」四条能直接改的路。

体验地址：https://xululu0401.github.io/tank-days/

## 它算什么

```
缸体几何 → 实际水量 V → 鱼重 × 投喂率的氮负荷 → 每天涨幅 a
        → ① 不换水还能撑几天      d = (上限 − 今天读数) / a
        → ② 换水节奏的稳态峰值     peak∞ = aT / f      （aT = a × 周期，f = 每次换水比例）
        → ③ 往后 8 周逐周排班       peak_k = after_{k−1} + aT,  after_k = peak_k × (1−f)
        → ④ 四条反解路（都按上限留 10% 余量）
```

## 模型假设（**都是本页自己的设计选择**）

| 假设 | 取值 | 说明 |
|---|---|---|
| 蛋白含氮 | 16%（即 ÷6.25） | 换算常数 |
| 氮 → 硝酸盐 | 62/14 = 4.428571… | 摩尔质量比 |
| 进水系数 | 默认 85% | 饲料氮里最终变成水里硝酸盐的比例 |
| 排班离散化 | 周期内线性上升、期末一次性换水 | 峰值与谷值与连续模型一致 |
| 建议值余量 | 10% | `f_req` 是临界值（峰值正好贴上上限、不会再低），建议值取 `1.10 × f_req` |

**没有引用任何机构、标准或文献**；页面文案里所有这类量都写明是「本页假设值，可改」。

## 它不做什么

- 不判断能不能养、养几条合适、鱼健不健康；上限由使用者自己填。
- 不预测氨氮与亚硝酸盐峰值，不模拟开缸养水，不涉及鱼病与用药。
- pH / 硬度 / 温度 / 溶解氧 / 反硝化都不在模型里；水草吸收按固定 mg/天。
- 默认场景与内置预设**全部是虚构示例**，不是真实鱼缸数据。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面（由 `template.html` 直接产出，脚本外链） |
| `core.js` | 纯函数内核：`AppCore.compute(state)`、导出（CSV/MD/JSON） |
| `ui.js` | 界面层：只画 `compute` 的结果、把点击改回输入 |
| `tests/core.test.cjs` | 核心测试，`node --test tests/core.test.cjs` |
| `build.cjs` | 把 `template.html` 产出 `index.html`（并挡住「源码被内联」） |
| `make-cover.cjs` | 由内核实算的数字生成 `cover.svg` |

## 跑起来

```bash
node build.cjs                      # 产出 index.html
node --test tests/core.test.cjs     # 核心测试
python3 -m http.server 8941         # 然后打开 http://127.0.0.1:8941/index.html
```

只算数与排版，不联网、不上传任何数据；填的数字只存在你自己的浏览器里。
AI 自行复核，未做人工校核。
